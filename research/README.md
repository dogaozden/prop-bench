# PropBench research record

This directory separates the experimental protocol, dataset facts, and release
checks from results. It does not assert that a planned campaign has run.

- [Protocol and campaign plan](PROTOCOL.md)
- [Dataset provenance and license facts](DATASET.md)
- [Reproduction and release evidence](REPRODUCIBILITY.md)
- [Interpretation and limitations](LIMITATIONS.md)
- [Publication claims checklist](PUBLICATION-CHECKLIST.md)
- [Independent semantic audit](SEMANTIC-AUDIT.md)
- [Pre-campaign methodology audit](PRE-CAMPAIGN-AUDIT.md)

The relevant evidence hierarchy is: independently replayed proof bytes; sealed
run and runtime identities; complete attempt/session/tool records; then derived
tables and narrative. A valid proof alone does not establish a compliant run.
Fixtures, historical pilots, and new controlled evaluations remain separately
labeled. New live experiments in this campaign use **Codex subscriptions only**.

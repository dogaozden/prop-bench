03HOW TO READ THIS

A length is a claim.
Verification makes it evidence.

A / INPUT

Frozen questions

Each run names its theorem selection and set identity. A par is a known achievable proof length for comparison; it does not establish the shortest possible proof.

B / REFEREE

Independent replay

The Rust verifier checks proof rules and scope. It counts submitted lines, including assumptions and closing lines. Premises supplied with the theorem are free.

C / SCORE

Lengths first

For a valid proof, loss is L/(L+P). Invalid or missing proofs have loss 1. Completed runs contribute to the condition mean; interrupted runs remain inspectable and are excluded. Coverage and verified lengths show what the mean conceals.

!

Interpretation boundary. Compare runs only when their protocol, selected items, budgets, and starting state align. The frozen set is small and may be familiar to models. A result documents observed search under stated conditions, not general reasoning ability, human equivalence, or a proof of mathematical optimality.
